# Sreekanth — Portfolio (with Admin Panel)

Live site: `https://YOUR-USERNAME.github.io/YOUR-REPO/`
Admin panel: `https://YOUR-USERNAME.github.io/YOUR-REPO/admin/`

**First login:** username `sreekanth` · password `Sreekanth@2026` — you are forced to choose your own on first sign-in.

## 1. Put it on GitHub (one time)
1. github.com → **New repository** → name e.g. `portfolio` → Public → Create.
2. Click **uploading an existing file**, drag in EVERYTHING from this folder (index.html, content.json, assets, images, admin, .nojekyll) → Commit.
   (Upload the folder contents, keep the folders `assets`, `images`, `admin`.)
3. Repo **Settings → Pages → Source: Deploy from a branch → main / (root) → Save.** After ~1 minute the site is live.

## 2. Connect the admin to GitHub (one time)
1. Open `/admin/` and sign in, choose your own login.
2. github.com/settings/personal-access-tokens/new → Repository access: only your portfolio repo → Permissions → **Contents: Read and write** → Generate → copy.
3. Admin → **Settings & GitHub** → enter username, repo name, paste token → **Save & test connection**.

## 3. Daily use
Quick post → add pictures → title/category → **Add** → **Publish**. Live in about a minute.
Everything else (texts, colours, fonts, sections, videos, contact) is in the left menu, with a live preview on the right.

## Notes
- The token is stored only in your browser. Never share it. The admin login only locks the editing screen; the token is the real protection.
- Open the admin from the https address, not by double-clicking the file.
- Videos: paste YouTube / Google Drive / Vimeo links (best), or upload clips under 45 MB.
